# GEN-AI Repository: Build Generative AI Apps with Real-World Use Cases 🚀🤖

## Welcome! 👋

Dive into the exciting world of **Generative AI** with this hands-on repository! Whether you're a developer, student, or AI enthusiast, this collection of real-world projects and tools will help you build, deploy, and understand the backbone of modern GenAI applications.

From PDF summarizers to YouTube blog generators and CrewAI character bots — this repo has everything to kickstart your GenAI journey! 🌟

---

## 🔍 What's Inside?

The repository is organized into modular folders, each representing a complete GenAI project with code, logic, and (sometimes) deployment links:

- **1_RAG:** Foundations of Retrieval-Augmented Generation (RAG).  
- **2_Chatbots:** Chatbots based on RAG, applied to PDFs for intelligent Q&A and I/O operations.  
- **3_Agents:** Agents capable of web search and querying SQL databases.  
- **4_Text_Summarizer:** A powerful tool to summarize YouTube videos and website content.  
- **5_Maths_Solver:** A chatbot designed to solve math problems using Gemma-2.  
- **6_HuggingFace_x_Langchain:** Combining the power of Hugging Face with LangChain.  
- **7_Pdf_Query:** Query PDFs using AstraDB as a vector store.  
- **8_Code_Assistant:** A code assistant that helps users with code-related queries and generation.  
- **9_Crew_AI_YouTube_Blog:** Automate YouTube blog creation using CrewAI-powered workflows.  
- **10_Character_Chat:** Talk to fictional characters from books or movies using context-aware RAG + LLM stack.  
- **11_Hybrid_Search:** Combine semantic and keyword search for better results.  
- **12_Neo4j:** A graph database with a chatbot to query it.  
- **13_Finetuning:** Notebooks and workflows for fine-tuning models.  
- **14_LangGraph:** Build multi-agent systems with tools using LangGraph.  
- **Chatbot:** A chatbot with a FastAPI backend and Streamlit UI.  
- *(...and many more on the way!)*

---

## 🛠️ Tech Stack

- **LangChain & CrewAI**: For agent workflows, tool integrations, and memory management.  
- **OpenAI / Groq / Gemini / NVIDIA / Hugging Face APIs**: LLM backends for various tasks.  
- **Streamlit / Gradio**: Used for building user interfaces.  
- **Python**: The core language used across all projects.  
- **Pydantic**: For data validation and model schema definitions.  
- **PDF / Web Tools**: Document loaders, search tools, and URL scrapers.  
- **MySQL / Neo4j / Pinecone / AstraDB**: Databases for structured, graph-based, vector, and cloud-native storage respectively.

## 🚀 How to Use

1. **Clone the repository**  
   ```bash
   git clone https://github.com/SachinGoyal94/GEN-AI.git
   cd GEN-AI
   ```

2. **Set up your environment**  
   - Create a virtual environment and install dependencies (usually via `requirements.txt`).  
   - Add your API keys in a `.env` file or set them as environment variables.

3. **Navigate to a project folder**  
   ```bash
   cd 1_RAG
   # or any other folder you want to explore
   ```

4. **Run the app**  
   Most apps can be run using:
   ```bash
   streamlit run app.py
   # or
   python main.py
   ```
